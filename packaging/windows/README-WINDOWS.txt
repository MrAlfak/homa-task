# راهنمای اجرای Homa Task روی سرور ویندوز (بدون داکر)
# Homa Task Windows Server Setup Guide

## مراحل اجرا (Execution Steps):

1. فایل زیپ `HomaTask-windows.zip` را در سرور ویندوز (مثلاً روی دسکتاپ یا پوشه C:\Apps) آنزیپ کنید.
2. پوشه حاصل شامل تمام وابستگی‌ها، مفسر پایتون و کدهای ربات است و نیازی به نصب پایتون یا اینترنت برای نصب پکیج ندارد.
3. فایل `.env` را بررسی کنید که توکن ربات (`BOT_TOKEN`) و شناسه شیت (`GOOGLE_SHEET_ID`) در آن وجود داشته باشد (از قبل همراه پکیج کپی شده است).
4. برای اجرا می‌توانید از یکی از دو روش زیر استفاده کنید:
   - روی **`HomaTask.exe`** دابل کلیک کنید.
   - یا روی **`start.bat`** دابل کلیک کنید.
5. پنجره کنسول باز شده و پیام‌های ربات و اتصال موفق به تلگرام نمایش داده می‌شود.
6. برای فعال ماندن ربات، پنجره کنسول را باز بگذارید (یا آن را Minimize کنید).

---

## نکات مهم (Important Notes):
- در ویندوز ربات به صورت مستقیم به تلگرام متصل می‌شود و نیازی به سرویس‌های VPN کانتینری ندارد.
- در صورت بروز هرگونه قطعی شبکه، ربات به طور خودکار مجدداً تلاش کرده و متصل می‌شود.
- در صورت نیاز به تغییر تنظیمات یا شیت، فایل `.env` را در کنار `HomaTask.exe` ویرایش کنید.
